# Brand assets — TRCON Group

| Arquivo | Uso |
|---------|-----|
| `trcon-mark.svg` | Monograma hex **TR** (nav, favicon, overlay de capa) |
| `trcon-lockup.svg` | Mark + wordmark **TR**ouro + **CONGROUP**branco |

Regras:

- O hex leva só **TR** (2 letras). Nome completo fica no wordmark.
- Não pedir o logo para a IA de imagem — overlay com este mark.
- Escala só via `width`/`height` ou `viewBox`; não distorcer o hex.
- Paleta: ouro `#FFD700` / `#C8960C`, ciano `#00D4FF`, fundo escuro.
